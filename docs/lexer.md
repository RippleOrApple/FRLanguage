# 词法分析器说明

本文档记录 FRLanguage 第一阶段 Lexer 的设计和当前支持范围。

## 职责

Lexer 负责把源码字符串转换成 Token 列表。它不理解语法结构，只负责识别最小词法单元。

处理流程：

```txt
源码字符串 -> 字符扫描 -> Token 列表
```

## 当前支持的 Token

单字符符号：

- `(`
- `)`
- `{`
- `}`
- `[`
- `]`
- `,`
- `:`
- `.`
- `-`
- `+`
- `;`
- `/`
- `*`

一到两个字符的运算符：

- `!`
- `!=`
- `=`
- `==`
- `>`
- `>=`
- `<`
- `<=`

字面量：

- 标识符
- 字符串
- 数字

关键字：

- `let`
- `fn`
- `return`
- `if`
- `else`
- `while`
- `break`
- `and`
- `or`
- `true`
- `false`
- `future`
- `await`
- `print`

特殊 Token：

- `EOF`

## 注释

当前支持单行注释：

```fr
// 这是注释
```

Lexer 会忽略从 `//` 到当前行末尾的内容。

## 字面量规则

数字：

```fr
123
12.5
```

字符串：

```fr
"hello"
```

布尔值：

```fr
true
false
```

## 位置信息

每个 Token 都会记录：

- 原始文本
- 字面量值
- 行号
- 列号

行号和列号都从 1 开始。

## 错误策略

当前 Lexer 会在以下情况抛出词法错误：

- 遇到无法识别的字符
- 字符串没有结束

错误信息包含行号和列号，便于后续在命令行入口中展示。
