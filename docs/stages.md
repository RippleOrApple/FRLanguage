# 阶段开发规划

本文档记录 FRLanguage 的阶段目标。项目核心原则是：规模小、结构清楚、先可用再扩展。

## 阶段 0：确定语言边界

第一版只支持最小可用语言能力：

- 变量声明
- 数字、字符串、布尔值
- 四则运算和比较运算
- `if` 条件分支
- `while` 循环
- 函数定义和函数调用
- `print` 内置函数
- `future` 和 `await`

暂时不做：

- 类和对象系统
- 泛型
- 模块系统
- 静态类型检查
- 字节码虚拟机
- 真正多线程运行时

## 阶段 1：词法分析器

目标：把源码拆成 Token。

示例：

```fr
let x = 1 + 2;
```

词法分析后应得到类似：

```txt
LET IDENT EQUAL NUMBER PLUS NUMBER SEMICOLON
```

重点内容：

- 字符扫描
- 关键字识别
- 字面量识别
- 行号和列号记录
- 词法错误报告

## 阶段 2：语法分析器

目标：把 Token 转成 AST。

建议使用递归下降解析器，因为它直观、容易调试，也适合学习语言实现。

重点内容：

- 表达式优先级
- 语句解析
- 函数定义
- 块作用域
- `await` 表达式

## 阶段 3：同步解释器

目标：先不考虑 Future，完成普通同步代码执行。

示例：

```fr
let x = 10;
print(x + 5);
```

重点内容：

- AST 求值
- 变量环境
- 运行时错误
- 条件分支
- 循环执行

## 阶段 4：函数和作用域

目标：支持自定义函数。

示例：

```fr
fn add(a, b) {
  return a + b;
}

print(add(1, 2));
```

重点内容：

- 函数对象
- 参数绑定
- 局部环境
- `return` 控制流
- 调用栈

## 阶段 5：Future 最小模型

目标：加入类似 Dart 的 Future，但保持实现足够简单。

推荐第一版语法：

```fr
fn delayValue(x) {
  return future {
    return x * 2;
  };
}

let value = await delayValue(21);
print(value);
```

第一版 Future 可以采用协作式调度，不做真正并行。

重点内容：

- Future 状态：`pending`、`resolved`、`rejected`
- 任务队列
- `await` 暂停当前任务
- Future 完成后恢复任务
- Future 错误传播

## 阶段 6：错误处理和开发体验

目标：让错误信息足够清楚，方便学习和调试。

示例：

```txt
第 3 行，第 8 列：变量 x 未定义
第 5 行：await 只能用于 Future
```

重点内容：

- 词法错误
- 语法错误
- 运行时错误
- Future 错误
- 错误位置展示

## 阶段 7：示例程序和测试

目标：用示例和测试证明语言行为稳定。

至少覆盖：

- 变量和表达式
- 条件分支
- 循环
- 函数调用
- 递归
- Future resolve
- `await`
- Future 错误
